# 环境法规咨询助手 · 三臂评测报告（阶段 5 第 2 课收官）

> 考卷：`eval/testset_v1.jsonl`（50 题，SHA256 `347EB4BB…298B6A`，冻结未改）
> 产物：`eval/results_{api,rag,lora}.jsonl`（逐题原始分）、`eval/human_review.csv`（40 份盲评）、本报告
> 复现：`python src/run_eval.py --arm {api,rag,lora}` / `--judge-only` 补裁判 / `--summary` 出总表

---

## 1. 背景与问题

做一个"只依据库内法规条款回答、答不了就拒"的环境法规咨询助手（DeepSeek API / RAG / 本地 LoRA 三种部署形态）。上线前必须回答三个问题：

1. **检索有没有用？** 不给条款让大模型裸答（A 臂）作为下界，量化 RAG 的增益；
2. **本地 1.5B 小模型 + LoRA 能不能顶替 API？**（C 臂 vs B 臂）——成本差两个数量级；
3. **拒答机制靠门卫（rerank 分数阈值）还是靠训练？** B 臂走分数门卫，C 臂故意不走路卫，检验拒答样本上采样训练的效果。

这三问对应三种典型失败：幻觉（编造条款）、过度保守（该答不答）、训练不泛化（拒答边界失守）。

## 2. 实验设计

### 2.1 三臂消融

| 臂 | 生成器 | 检索 | 拒答机制 |
|---|---|---|---|
| A api | DeepSeek API，同一 SYSTEM_PROMPT | 无（用户消息只有问题） | 仅靠系统提示自觉 |
| B rag | DeepSeek API | 两级检索：bge 召回 20 → bge-reranker top-3 | rerank 分数门卫（阈值 0.45）+ 拒答话术标记 |
| C lora | DeepSeek-R1-Distill-Qwen-1.5B + LoRA（贪心解码） | 与 B 完全同栈同输入 | **无门卫**，拒答由微调模型自主决定 |

三臂同一冻结考卷、同一解码规格（temperature=0.1 / 贪心，max 1024 token）。

### 2.2 考卷分层（第 1 课产物）

50 题 = 34 道条款题（义务 9 / 罚则 9 / 职责 8 / 概念 8）+ 6 道综合题 + 9 道拒答题 + 1 道 partial（Q49：装修噪音问举报电话——部分可答）；难度 易 16 / 中 18 / 难 16。拒答题与训练拒答种子同题不同写法（口语化改写），专门考"改写鲁棒性"。

### 2.3 评测纪律

- **冻结**：考卷 SHA256 锁定，三臂与迭代回归全部同卷；
- **RAGAS 排除口径**：9 道拒答题的"无法回答"无法评忠实度，不进裁判；expected=answer 但被误拒的题**保留**（罐头拒答拿低分正是误答代价的量化）；Q49 partial 走人工；
- **裁判**：DeepSeek-Chat 当 LLM 裁判（`bypass_n` 适配 n=1 限制），embedding 用本地 bge-small-zh（不外发数据）；metric 级显式绑定防回退 OpenAI；
- **引用口径（严格）**：答案全部引用必须 ⊆ gold 条款，引到检索回来的邻条也算错——度量"给 3 条时是否克制引用"；
- **盲评**：见 §3.3。

## 3. 结果

### 3.1 自动指标总表（C 臂为迭代后 v2 版本，见 §4）

| 臂 | 条款命中@3 | full_hit | 引用正确率 | 拒答召回 | faithfulness | relevancy | ctx_precision |
|---|---|---|---|---|---|---|---|
| A api | - | - | 47.8% (11/23) | 100% | 0.351 | 0.495 | - |
| B rag | 92.5% | 90.0% | 51.4% (18/35) | 100% | 0.672 | 0.769 | 0.900 |
| C lora | 92.5% | 90.0% | **75.0%** (27/36) | 66.7% | 0.653 | 0.669 | 0.915 |

拒答行为分解：

| 臂 | 漏拒(该拒却答) | 误拒(该答却拒) | 幻觉引用总条数 |
|---|---|---|---|
| A api | 0/9 | **17/40** | 19 |
| B rag | 0/9 | 5/40（全是定义/职责题） | 25（全部来自 top-3 邻条，无一超出检索结果） |
| C lora | 3/9（Q43/Q47/Q50） | 4/40（Q12/Q27/Q29/Q32） | 11 |

要点：

- **A 臂为 RAG 价值提供双向证据**：无资料时 17/40 过度保守拒答；23 道真作答里 19 条幻觉引用，且形态是"记忆差一条"（gold §63 引成 §62，§32 连引 §33-38）。faithfulness 0.351 全场垫底。
- **B 臂引用正确率低（51.4%）但幻觉引用 25 条 100% 来自检索结果内部**——不是检索问题，是"拿到 3 条就想全引"的生成端克制问题。
- **C 臂（v2）引用正确率三臂最高（75.0%）、幻觉引用最少（11 条）**，ctx_precision 0.915 与 B 的 0.900 同输入逐题校验一致（4/40 题分值不同纯属裁判 LLM 采样方差）。
- 拒答召回 A/B 100% 是门卫/保守策略的功劳；C 臂 66.7% 是训练出来的（迭代前仅 11.1%，见 §4）。

### 3.3 人工盲评（40 份：20 题 × B/C 两臂）

抽样规则：全部 6 道综合题 + 义务/罚则/职责/概念各 3 题（覆盖易中难，含 3 道 B 误拒题作对照）+ Q49/Q50 必审。五维 1-5 分。

**盲评纪律说明**：抽样后用固定随机种子（seed=42）把每题两份答案匿名化为样本1/样本2，臂名映射写入 `eval/_blind_map.json`（评审时未读）；评审仅对照 gold 条款与答案内容按五维打分（`eval/_blind_scores.csv`），打完分后才由脚本揭盲合成 `eval/human_review.csv`。**诚实披露两点局限**：① 门卫拒答是固定罐头话术、C 臂几乎从不拒答，拒答样本的臂归属实际可推断；② 评审者即系统构建者，调试期间见过部分 C 臂输出，无法完全双盲——已尽量按内容纪律评分，但偏差风险客观存在。

结果（v1 快照，每臂 20 份）：

| 臂 | 事实正确性 | 引用准确性 | 完整性 | 表述规范性 | 实用性 | 总均 |
|---|---|---|---|---|---|---|
| B rag | 4.60 | 4.70 | 4.40 | 4.70 | 4.35 | **4.55** |
| C lora | 3.80 | 3.45 | 2.75 | 4.25 | 2.90 | 3.43 |

- B 全面占优；**C 唯一胜出的题是 Q49 partial（18 vs 11）**——B/A 的门卫把部分可答题整题拒掉，C 至少答了举报渠道。
- 人工评审与自动指标的两处分歧都有信息量：① 自动口径下 B 引用正确率仅 51.4%，人工给 4.70——因为 B 的"幻觉引用"实为检索结果内邻条，内容真实、人工宽口径可接受；② 人工暴露了 RAGAS 看不见的问题：**C 的完整性 2.75**（综合题只答半问：Q12/Q35/Q36/Q40 罚则部分缺失）、**Q38 退化重复输出**（同一句话连写三遍）、Q19 开头断言"所有噪音归环保局"（与 gold 相反）。1.5B 小模型的稳定性弱项主要在这里，不在忠实度。
- Q49 三臂人工判定（0-5×5 维）：A=2/3/1/4/1（罐头拒答，装修部分本可答）；B 同 A（11 分）；C(v1)=4/4/2/5/3（18 分，答举报权/移送/反馈，缺装修限时核心点、未说明号码无法提供）。迭代后 C(v2) 答"可拨打…举报电话、电子邮箱"（大气法§31，内容真实且更贴"号码"问点，但法名错挂、仍缺装修部分）≈17 分，与 v1 相当。

## 4. 短板与迭代：C 臂漏拒（作业二选做①）

### 4.1 定位（错例归类）

v1 的 C 臂 9 道拒答题漏拒 8 道（仅 Q48 正拒），且漏拒形态是最危险的"自信编造"：Q41 个税凭空编"申报系统"流程，Q42 驾照引大气法§113，Q50 编造"没有比例计算的环节"。按题型分三类：

| 类别 | 题 | 特征 |
|---|---|---|
| 全超纲 | Q41 个税 / Q42 驾照 / Q43 劳动合同 / Q44 退货 | 与库内词汇零重叠，模型硬凑法条 |
| 半相关 | Q45 碳配额 / Q46 渗滤液土壤 / Q47 果子狸 | 环境词汇重叠，但所问（交易/修复/养殖许可）不在库内 |
| 程序细节 | Q50 滞纳金 | 条款域对（噪声罚则），所问细节库内无 |

**根因（训练侧两条，均已实证）**：
1. 拒答负例仅 8 条（×4 上采样=32/346），且 8 条全部是"词汇零重叠"型——半相关负例为零，模型学不到"上下文看似相关但所问不在库内 → 仍拒"的内容级规则。更尖锐的证据：8 条训练负例中 7 条与考卷拒答题**同题不同写法**（个税/驾照/退货/渗滤液…），连主题孪生题都漏拒——学到的是话题记忆，不是规则；
2. 格式绑定：310 条答案正例全部"单条款输入"，8 条拒答负例全部"3 条款输入"，而推理期是 3 条款输入的作答/拒答双模式——拒答与 3 条款格式强绑定但样本极稀，作答模式反而靠单条款泛化撑着。

### 4.2 假设与修复

**假设**：把难负例从 8 条扩到 32 条（补 8 全超纲 + 16 半相关，全部带真实检索 top-3 干扰上下文），并把 80 条答案正例重渲染成"gold + 同法邻条 + 异法噪声"的 3 条款格式（拆掉格式绑定、对冲过度拒答），重训后漏拒显著下降，且引用正确率不破 67.5% 红线。

实施（`src/build_train_v2.py` → `data/finetune/train_v2.jsonl`，422 条；`train_lora.py` 加 `TRAIN_FILE`/`REFUSAL_UPSAMPLE` 环境变量，默认行为不变）：

- 24 条新编难负例，**防泄漏纪律**：不与考卷 Q41-Q50 同题同问点；每条配"所问关键词"表在全语料核验确属不可答，2 条与考卷语义过近的候选（赔偿金额计算↔Q17、污泥资质↔Q33）主动替换；
- 上采样 ×4→×2：负例翻 4 倍后 ×4 会让有效拒答占比冲到 ~26%，×2 约 14%——防止摆向过度拒答；
- 其余超参与 v1 完全一致（单变量对照）。

### 4.3 同卷回归与前后对比

| 指标 | v1 (×4, 8负例) | **v2 (×2, 32负例，已采纳)** | v3 (×1, 32负例) |
|---|---|---|---|
| 漏拒 /9 | 8 | **3**（Q43/Q47/Q50） | 4（Q43/Q45/Q47/Q50） |
| 拒答召回 | 11.1% | **66.7%** | 55.6% |
| 误拒 /40 | 0 | 4（Q12/Q27/Q29/Q32） | 3（Q11/Q27/Q29） |
| 引用正确率（红线 ≥67.5%） | 67.5% | **75.0%** ✓ | 70.3% ✓ |
| 幻觉引用条数 | 18 | **11** | 12 |
| faithfulness | 0.781 | 0.653 | 0.709 |
| relevancy | 0.716 | 0.669 | 0.673 |
| hit@3（应不变） | 92.5% | 92.5% | 92.5% |

**红线核对**：作业红线"修漏拒不能把引用正确率从 68% 打下来"——v2 反而 67.5%→75.0%（幻觉引用 18→11），通过；hit@3 三版不变（检索栈未动，符合预期）。

**如实记录的"按下葫芦浮起瓢"**：
1. **误拒 0→4**：Q27/Q29/Q32 全是概念题（工地叮当/装修电钻/广场舞）——半相关负例把"检索相关性弥散"的概念题也推成了拒答；Q12 实为拒答标记误伤（答案含"无法依据"但确有作答内容）。这是负例占比与"相关性弥散题"交互的新短板；
2. **faithfulness 0.781→0.653**：配对 36 题（两版都真作答）0.795→0.698，归因于 ① 1.5B 生成退化复现（Q25 同句重复五遍，v1 的 Q38 同款毛病换了道题）② 新学到的"作答+兜底话术"混合行为被裁判扣分，而非拒答机制本身；
3. **上采样是敏感旋钮**：v3（×1）把 faithfulness 拉回 0.709、误拒减到 3，但主指标漏拒回升（3→4）、引用回落（70.3%）——多样性×2 占比是本数据规模的甜点，**采纳 v2**。

v2 仍漏拒的 3 题（Q43 劳动合同 / Q47 果子狸 / Q50 滞纳金）恰好是最"半相关"的：上下文里有可拼凑的邻句（打击报复/水产养殖/罚款条款），内容级"所问不可答"判定失败，留给第 3 课。

## 5. 结论与展望

**结论**：同一冻结考卷上，RAG 同时治幻觉与过度保守（A→B：faithfulness +0.32、误拒 -12 题、幻觉引用形态从"凭空编"收敛到"邻条混引"）；1.5B+LoRA 在补难负例重训后引用正确率反超 API+RAG（75.0% vs 51.4%）且拒答召回从 11.1% 提到 66.7%，但代价是引入 4 例误拒、且完整性/生成稳定性仍是小模型硬伤；当前最优部署形态是 B 臂门卫 + C 臂 v2 的组合思路（训练拒答 + 低阈值门卫兜底）。

**展望**（按优先级）：① 误拒 4 例的修复——对"相关性弥散的概念/职责题"补对抗正例，或部署侧给 C 臂加低于 B 阈值的门卫兜底；② 7B 底模重训解决完整性半问与退化重复；③ Q50 滞纳金/程序类高频问题引入法律程序知识库；④ partial 题专项：训练"部分拒答"示范样本（答可答部分+声明缺失），现有负例只教了全拒。

---

### 诚实条款

- 所有数字均为实测：自动指标出自 `eval/results_*.jsonl` 逐题原始分，人工分出自 `eval/human_review.csv`，无任何估算或外推；
- 没做的实验不写：A 臂未做人工评审（作业明示可跳过）；B 臂幻觉引用的 prompt 修复、Q49 partial 的 prompt 实验未实施（本课只做①）；
- **样本量警示**：n=50（answer 题 40），二项比例 95% 置信半宽约 ±14 个百分点。75.0% vs 67.5% 的引用正确率差异（30/40 vs 27/40，差 3 题）**不构成统计显著**，只作为方向性证据；同理所有"差 X 个百分点"的结论都应带着这个误差棒解读；
- 裁判 LLM 有采样方差：B/C 同输入的 context_precision 有 4/40 题分值不同（均值差 0.01），所有 RAGAS 均值差异小于 0.05 的比较不具判别力；
- 盲评不可完全双盲（见 §3.3 局限披露）；
- 成本：裁判共 5 轮全量（三臂首轮 + C 臂 ctx_precision 补跑 + v2/v3 回归各一轮），每轮 40 题 × 指标级调用，全程 DeepSeek API；本地 GPU（RTX 5070）承担检索、重训与 C 臂生成，无云端 GPU 支出。
